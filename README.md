# InvestSimples
Thesis project on investments

# Para rodar o projeto:

## backend
- entrar no diretório "./backend"
``cd .\backend``
- Criar venv 
`` venv\Scripts\activate ``
- inicializar o uvicorn
``uvicorn main:app --reload``
- ligar o supabase


## frontend
- entrar no diretório "./frontend"
``cd .\frontend``
- inicializar o react
``npm run dev``


# Portas:

http://localhost:5173/

- Porta padrão FastAPI
